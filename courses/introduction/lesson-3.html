Variables & Data

    Learning material

    Variables: giving a value a name

    So far your programs have had no memory. They print something and forget it. A variable is a name attached to a value, so the program can keep hold of information and use it again later. 

    name = "Alex"
age = 20

    Read the = as "is set to", not as "equals". It is an instruction, not a statement of fact: take the value on the right, and attach the name on the left to it. Afterwards, writing name anywhere in your program means "Alex". 

    name = "Alex"
print("Hello,", name)
    Output 
    Hello, Alex

    Why variables exist

    Because information that is used twice should be written once. If a price appears in six places in your program and it changes, you have six chances to miss one. Stored in a variable, it changes in a single place and every use follows.

    Variables can be reassigned

    score = 0
print(score)

score = 10
print(score)
    Output 
    0
10

    The old value is simply gone. A variable holds one value at a time — the most recent one it was given.

    Tip — naming

    Use lowercase words joined by underscores: first_name, total_price, is_finished. Names cannot contain spaces, cannot start with a digit, and should say what the thing is. x and data2 will cost you time later.

    Data types

    Every value has a type, and the type decides what you can do with it. Adding two numbers gives you their sum; adding two pieces of text glues them together. Python needs to know which you meant, so it tracks the type of everything.

    The four types you need now:

    • str (string) — text, always in quotes: "Alex", "20", ""
    • int (integer) — whole numbers, no quotes: 20, 0, -7
    • float — numbers with a decimal point: 4.50, -0.5, 3.0
    • bool (boolean) — one of exactly two values: True or False

    You can ask Python what type something is:

    print(type("Alex"))
print(type(20))
print(type(4.50))
print(type(True))
    Output 
    <class 'str'>
<class 'int'>
<class 'float'>
<class 'bool'>
    Careful

    20 and "20" are not the same thing. One is a number you can do arithmetic with; the other is two characters of text that happen to look like a number. This single distinction causes more beginner confusion than any other idea in this chapter.

    Strings

    A string is a sequence of characters. Single and double quotes both work, which is handy when the text itself contains a quote: 

    greeting = "Hello"
name = 'Alex'
message = "It's a nice day"

    Joining strings together is called concatenation, and uses +: 

    first = "Ada"
last = "Lovelace"
full = first + " " + last
print(full)
    Output 
    Ada Lovelace

    Note the " " in the middle. Without it you would get AdaLovelace — Python adds exactly what you tell it to and no helpful spaces of its own.

    f-strings: the tidier way

    Building sentences with + gets ugly fast. An f-string lets you drop variables straight into text. Put an f before the opening quote and wrap each variable in curly braces: 

    name = "Alex"
age = 20
print(f"{name} is {age} years old")
    Output 
    Alex is 20 years old

    Numbers

    Integers and floats behave as you would expect from school arithmetic: 

    price = 4.50
quantity = 3
total = price * quantity
print(total)
    Output 
    13.5

    You will meet the full set of arithmetic operators in the next chapter. For now, know that numbers are stored without quotes, and that mixing an int and a float gives you a float.

    Boolean values

    A boolean is either True or False — capitalised exactly like that, and without quotes. Booleans exist to record whether something is the case, which is what lets a program make decisions in Chapter 5. 

    is_logged_in = True
has_paid = False

print(is_logged_in)

    Comparisons produce booleans, which is where they usually come from in real programs: 

    age = 20
print(age >= 18)
    Output 
    True

    User input

    A program that only ever works with values you typed into the file is not much use. input() pauses the program, waits for the person to type something and press Enter, and hands back what they typed. 

    name = input("What is your name? ")
print(f"Hello, {name}!")
    Output (with "Alex" typed) 
    What is your name? Alex
Hello, Alex!

    The text inside the brackets is the prompt — it is shown before the program waits. Ending it with a space stops the person's typing from butting against your question mark.

    Careful — this one catches everybody

    input() always gives you a string. Even if the person types 20, you get the text "20", not the number 20.

    Which leads directly to this trap:

    age = input("Your age: ")
print(age + 1)
    Output 
    TypeError: can only concatenate str (not "int") to str

    Python is telling you, in its own way, that you asked it to glue a number onto some text and it does not know how.

    Type conversion

    Type conversion — also called casting — turns a value of one type into another. Three functions cover almost everything you need:

    • int(x) — make a whole number
    • float(x) — make a decimal number
    • str(x) — make text
    age = int(input("Your age: "))
print(f"Next year you will be {age + 1}")
    Output (with "20" typed) 
    Your age: 20
Next year you will be 21

    Read int(input("Your age: ")) from the inside out: input collects text, and int converts that text into a number. Wrapping one call around another like this is extremely common.

    Careful

    int("hello") fails with a ValueError — there is no sensible number in "hello". Converting only works when the text genuinely looks like a number.

    Worked example — the Personal Information Program

    This chapter's project pulls every idea together: input, storage, conversion, types and formatted output. 

    # Personal Information Program

name = input("What is your name? ")
age = int(input("How old are you? "))
city = input("Where do you live? ")
height = float(input("How tall are you in metres? "))

print()
print("--- Your details ---")
print(f"Name:   {name}")
print(f"Age:    {age}")
print(f"City:   {city}")
print(f"Height: {height} m")
print(f"In ten years you will be {age + 10}.")
    Output 
    What is your name? Alex
How old are you? 20
Where do you live? Jakarta
How tall are you in metres? 1.72

--- Your details ---
Name:   Alex
Age:    20
City:   Jakarta
Height: 1.72 m
In ten years you will be 30.

    Note which inputs were converted and which were not. name and city stay as text because they are text. age becomes an int and height a float, because both are used in arithmetic. Choosing the right type for each value is a real decision, and you just made four of them.
