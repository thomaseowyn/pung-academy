    Learning material

    Why loops?

    Suppose you want to count from 1 to 5. You could write:

    print(1)
print(2)
print(3)
print(4)
print(5)

    Now count to a thousand. The approach collapses immediately, and that is before anyone asks you to change the wording — five edits becomes a thousand edits.

    A loop runs the same block of code repeatedly. Write the instruction once, and say how many times or under what condition it should repeat. Loops are the first moment programming starts feeling like leverage rather than typing.

    The for loop

    A for loop repeats once for each item in a sequence. The most common way to produce that sequence is range(). 

    for number in range(1, 6):
    print(number)
    Output 
    1
2
3
4
5

    Reading it aloud: "for each number in the range 1 up to 6, print it."

    • number is the loop variable. You choose the name; it holds a different value each time round.
    • range(1, 6) produces 1, 2, 3, 4, 5.
    • The colon and the indented body work exactly as they did for if.
    Careful — the off-by-one trap

    range(1, 6) stops before 6. The second number is where it stops, not the last value produced. To count to 10 you need range(1, 11). Nearly every programmer has shipped a bug from this at some point.

    The three forms of range()

    range(5)          # 0, 1, 2, 3, 4       -- starts at 0
range(2, 6)       # 2, 3, 4, 5          -- start and stop
range(0, 10, 2)   # 0, 2, 4, 6, 8       -- start, stop, step

    Accumulating a result

    Loops become genuinely useful when they build something up. The pattern: create a variable before the loop, change it inside. 

    total = 0

for number in range(1, 11):
    total += number

print(f"The sum of 1 to 10 is {total}")
    Output 
    The sum of 1 to 10 is 55

    total must be created before the loop. Put it inside and it resets to zero on every pass, and your answer is always the last number.

    The while loop

    A while loop repeats for as long as a condition stays True. Use it when you do not know in advance how many repetitions you need. 

    count = 1

while count <= 5:
    print(count)
    count += 1
    Output 
    1
2
3
4
5

    Every while loop needs three things, and missing any one breaks it:

    1. Something set up before the loop (count = 1)
    2. A condition that can become False (count <= 5)
    3. Something inside the body that moves towards that (count += 1)
    Careful — infinite loops

    Delete count += 1 and the condition never becomes False. The program prints 1 forever. If that happens, press Ctrl + C to stop it. Every programmer writes one; the trick is recognising it fast.

    Choosing between for and while

    • Known number of repetitions — a for loop. "Do this ten times", "go through this list".
    • Unknown, condition-driven — a while loop. "Keep asking until they type a valid answer", "keep playing until the game is won".

    The classic while-loop job is validating input:

    answer = ""

while answer != "yes" and answer != "no":
    answer = input("Please type yes or no: ")

print(f"You said {answer}")

    break and continue

    Two statements change the flow of a loop from inside it.

    break — leave the loop entirely

    for number in range(1, 11):
    if number == 4:
        break
    print(number)

print("Done")
    Output 
    1
2
3
Done

    When number reaches 4 the loop stops immediately. Numbers 4 to 10 are never reached.

    continue — skip to the next repetition

    for number in range(1, 11):
    if number % 2 != 0:
        continue
    print(number)
    Output 
    2
4
6
8
10

    Odd numbers hit continue, which abandons the rest of the body and jumps to the next value. The loop itself carries on — that is the difference from break.

    Note

    break is often paired with while True: — a loop with a condition that is always True, deliberately exited from inside. You will use exactly that shape for the menu in the final project.

    Worked example — the Number Guessing Game

    This chapter's project. It uses a while loop because nobody knows how many guesses it will take, and break to end the moment the answer is right. 

    # Number Guessing Game

import random

secret = random.randint(1, 20)
guesses = 0

print("I am thinking of a number between 1 and 20.")

while True:
    guess = int(input("Your guess: "))
    guesses += 1

    if guess < secret:
        print("Too low.")
    elif guess > secret:
        print("Too high.")
    else:
        print(f"Correct! It took you {guesses} guesses.")
        break
    Output 
    I am thinking of a number between 1 and 20.
Your guess: 10
Too low.
Your guess: 15
Too high.
Your guess: 13
Correct! It took you 3 guesses.

    import random brings in a module of ready-made code — here, randint, which picks a random whole number. Python ships with a great deal of this, and using it is normal rather than cheating.

    Small exercise

    How many lines does each of these print, and why do they differ? 

    for i in range(3):
    print("A")

for i in range(1, 3):
    print("B")

    Three A's — range(3) gives 0, 1, 2. Two B's — range(1, 3) gives 1, 2.
