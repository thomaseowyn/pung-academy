    Learning material

    Why sequences exist

    Storing one number is easy. Storing thirty is not — not with the tools you have so far. You cannot loop over thirty separate variables, and adding a thirty-first means editing the program. A sequence holds many values, in order, under one name.

    Lists

    A list is an ordered, changeable collection. Square brackets, commas between items: 

    grades = [78, 91, 65, 84, 72]
names = ["Alex", "Bo", "Chris"]

    len() tells you how many items a list holds:

    print(len(grades))    # 5

    Tuples

    A tuple looks almost identical to a list but uses round brackets, and — unlike a list — it cannot be changed after it is created. 

    point = (3, 7)
print(point[0])   # 3

    Use a tuple when a value should never change once it exists — coordinates, a fixed pair of settings. Use a list for anything you expect to grow, shrink or reorder.

    Indexing: reaching one item

    Each item has a position, called its index. Indexes start at 0, not 1. 

    names = ["Alex", "Bo", "Chris"]

print(names[0])    # Alex
print(names[1])    # Bo
print(names[2])    # Chris

    Counting from zero feels wrong for about a week and then becomes invisible. The consequence worth memorising: the last item of a list of length 5 sits at index 4. 

    print(names[-1])   # Chris  -- negative counts back from the end
print(names[-2])   # Bo
    Careful

    Asking for an index that does not exist crashes with IndexError: list index out of range. With three items, names[3] is already past the end.

    Slicing: reaching a whole chunk

    A slice takes several items at once, written list[start:stop]. The item at start is included; the item at stop is not. 

    letters = ["a", "b", "c", "d", "e"]

print(letters[1:4])    # ['b', 'c', 'd']
print(letters[:2])     # ['a', 'b']       -- start defaults to 0
print(letters[3:])     # ['d', 'e']       -- stop defaults to the end
print(letters[1:-1])   # ['b', 'c', 'd']  -- everything except first and last

    [1:-1] reads naturally once you know -1 means "the last item" — it is "from index 1 up to, but not including, the last one."

    List methods

    Lists can be changed after they are created.

    tasks = ["Wash up", "Email tutor"]

tasks.append("Buy milk")        # add to the end
print(tasks)                    # ['Wash up', 'Email tutor', 'Buy milk']

tasks.pop()                     # remove and return the last item
print(tasks)                    # ['Wash up', 'Email tutor']

tasks.sort()
print(tasks)                    # ['Email tutor', 'Wash up']
    Careful — mutability

    Because lists can change, be careful with a = b where b is a list — a and b then both point at the same list, so changing one changes the other. You will meet this properly, with the fix, in the next chapter.

    Looping through a sequence

    grades = [78, 91, 65, 84, 72]
total = 0

for grade in grades:
    total += grade

print(f"Average: {total / len(grades)}")
    Output 
    Average: 78.0

    No indexes needed — the loop variable takes each value in turn.

    Finding the largest value by hand

    grades = [78, 91, 65, 84, 72]
highest = grades[0]

for grade in grades:
    if grade > highest:
        highest = grade

print(f"Highest: {highest}")     # 91

    Start by assuming the first item wins, then replace it whenever something better appears. This "running best" pattern appears everywhere once you notice it.

    Worked example — the Caesar Cipher

    This chapter's project encrypts a message by shifting every letter forward in the alphabet by a fixed amount, using string indexing, list building and the modulo operator to wrap around from z back to a. 

    # Caesar Cipher

alphabet = "abcdefghijklmnopqrstuvwxyz"
message = input("Message to encrypt: ").lower()
shift = int(input("Shift amount: "))

encrypted = []

for letter in message:
    if letter in alphabet:
        position = alphabet.index(letter)
        new_position = (position + shift) % 26
        encrypted.append(alphabet[new_position])
    else:
        encrypted.append(letter)

print("Encrypted:", "".join(encrypted))
    Output 
    Message to encrypt: hello world
Shift amount: 3
Encrypted: khoor zruog

    alphabet.index(letter) finds a letter's position using a list method you have not met yet — it works the same way on strings. % 26 is what wraps the shift back to the start of the alphabet once it runs past z, and "".join(encrypted) turns the list of letters back into one string.

    Small exercise

    What does letters[2:2] print, for letters = ["a", "b", "c", "d"]? An empty list — the slice starts and stops at the same index, so it contains nothing.
