    Learning material

    Why loops?

    Suppose you want to count from 1 to 5. You could write:

    print(1)
print(2)
print(3)
print(4)
print(5)

    Now count to a thousand. The approach collapses immediately. A loop runs the same block of code repeatedly — write the instruction once, and say how many times, or under what condition, it should repeat.

    The for loop

    A for loop repeats once for each item in a sequence. The most common source of that sequence is range(). 

    for number in range(1, 6):
    print(number)
    Output 
    1
2
3
4
5
    • number is the loop variable — it holds a different value each time round.
    • range(1, 6) produces 1, 2, 3, 4, 5.
    Careful — the off-by-one trap

    range(1, 6) stops before 6. The second number is where it stops, not the last value produced. To count to 10 you need range(1, 11). 

    range(5)          # 0, 1, 2, 3, 4       -- starts at 0
range(2, 6)       # 2, 3, 4, 5          -- start and stop
range(0, 10, 2)   # 0, 2, 4, 6, 8       -- start, stop, step

    Accumulating a result

    Loops become genuinely useful when they build something up. The pattern: create a variable before the loop, change it inside. 

    total = 0

for number in range(1, 11):
    total += number

print(f"The sum of 1 to 10 is {total}")
    Output 
    The sum of 1 to 10 is 55

    total must be created before the loop. Put it inside and it resets to zero every pass.

    The while loop

    A while loop repeats for as long as a condition stays True. Use it when you do not know in advance how many repetitions you need. 

    count = 1

while count <= 5:
    print(count)
    count += 1
    Output 
    1
2
3
4
5

    Every while loop needs three things:

    1. Something set up before the loop (count = 1)
    2. A condition that can become False (count <= 5)
    3. Something inside the body that moves towards that (count += 1)
    Careful — infinite loops

    Delete count += 1 and the condition never becomes False — the program prints 1 forever. If that happens, press Ctrl + C to stop it.

    Choosing between for and while

    • Known number of repetitions — a for loop.
    • Unknown, condition-driven — a while loop. "Keep asking until they type a valid answer."

    break and continue

    Two statements change the flow of a loop from inside it.

    break — leave the loop entirely

    for number in range(1, 11):
    if number == 4:
        break
    print(number)

print("Done")
    Output 
    1
2
3
Done

    continue — skip to the next repetition

    for number in range(1, 11):
    if number % 2 != 0:
        continue
    print(number)
    Output 
    2
4
6
8
10

    Odd numbers hit continue, which abandons the rest of that pass and jumps to the next value. The loop itself keeps going — that is the difference from break.

    Nested loops

    A loop can contain another loop. The inner loop finishes all of its repetitions for each single pass of the outer one. 

    for row in range(1, 4):
    for column in range(1, 4):
        print(f"({row}, {column})", end=" ")
    print()
    Output 
    (1, 1) (1, 2) (1, 3)
(2, 1) (2, 2) (2, 3)
(3, 1) (3, 2) (3, 3)

    For every value of row, the inner loop runs completely through every value of column before row moves on. Grids, tables and anything two-dimensional lean on this shape.

    Small exercise

    How many lines does each of these print, and why do they differ? 

    for i in range(3):
    print("A")

for i in range(1, 3):
    print("B")

    Three A's — range(3) gives 0, 1, 2. Two B's — range(1, 3) gives 1, 2.
