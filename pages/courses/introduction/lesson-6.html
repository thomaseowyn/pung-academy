    Learning material

    Dictionaries: looking things up by name

    A list is indexed by position, which is fine when order is what matters. Often it is not — you want to look something up by name. A dictionary stores key-value pairs. Curly braces, each entry key: value: 

    student = {
    "name": "Alex",
    "age": 20,
    "grade": 78
}

    You look values up by key, not by position:

    print(student["name"])    # Alex
print(student["grade"])   # 78

    Changing and adding

    student["grade"] = 85          # change an existing value
student["city"] = "Jakarta"    # a new key simply appears
del student["age"]             # remove a pair

print(student)
    Output 
    {'name': 'Alex', 'grade': 85, 'city': 'Jakarta'}
    Careful

    Asking for a key that does not exist raises KeyError. Looking up safely is exactly what the next section is for.

    Dictionary methods: .get(), .keys(), .values(), .items()

    student = {"name": "Alex", "grade": 78}

print(student.get("grade"))              # 78
print(student.get("city", "Unknown"))    # Unknown -- the default, since "city" is missing

print(list(student.keys()))     # ['name', 'grade']
print(list(student.values()))   # ['Alex', 78]

for key, value in student.items():
    print(key, "->", value)

    .get(key, default) never raises KeyError — it hands back default instead when the key is missing, which makes it the safe way to read a dictionary you are not certain about. .items() is what lets a loop unpack both the key and the value at once.

    Sets: uniqueness without order

    A set holds values with no duplicates and no guaranteed order. Curly braces, but no colons: 

    colours = {"red", "green", "blue", "red"}
print(colours)          # {'red', 'green', 'blue'} -- the duplicate is gone

a = {1, 2, 3}
b = {2, 3, 4}
print(a & b)   # {2, 3}         -- intersection: in both
print(a | b)   # {1, 2, 3, 4}   -- union: in either

    Turning a list into a set is the fastest way to remove duplicates: 

    numbers = [1, 2, 2, 3, 3, 3]
unique = set(numbers)
print(unique)    # {1, 2, 3}

    Nested data structures

    Structures can hold other structures — a list of dictionaries, or a dictionary whose values are themselves dictionaries. This shape is everywhere once you start working with real data: API responses, JSON files, database records. 

    students = [
    {"name": "Alex", "grade": 78},
    {"name": "Bo", "grade": 91}
]

for student in students:
    print(f"{student['name']}: {student['grade']}")
    Output 
    Alex: 78
Bo: 91

    enumerate() and zip()

    enumerate() gives you the position and the value together while looping: 

    names = ["Alex", "Bo", "Chris"]

for position, name in enumerate(names, start=1):
    print(f"{position}. {name}")
    Output 
    1. Alex
2. Bo
3. Chris

    zip() walks two sequences together, pairing them up item by item: 

    names = ["Alex", "Bo"]
scores = [78, 91]

for name, score in zip(names, scores):
    print(name, score)
    Output 
    Alex 78
Bo 91

    Mutability and aliasing

    This is worth taking slowly, because it causes real bugs. Writing a = b for a list does not copy the list — it makes a and b two names for the exact same list. 

    original = [1, 2, 3]
alias = original

alias.append(4)
print(original)   # [1, 2, 3, 4]  -- changed too, even though we edited "alias"

    To get an independent copy, say so explicitly:

    original = [1, 2, 3]
copy = original.copy()

copy.append(4)
print(original)   # [1, 2, 3]  -- untouched
print(copy)        # [1, 2, 3, 4]
    Tip

    This same aliasing happens when you pass a list into a function — the function receives the same list, not a copy. Keep it in mind once you reach functions in the next chapter.

    Worked example — the Student Grade Analyzer

    This chapter's project puts nested structures, aggregation and enumerate() to work together. 

    # Student Grade & Class Performance Analyzer

students = [
    {"name": "Alex", "scores": [78, 82, 91]},
    {"name": "Bo", "scores": [91, 95, 89]},
    {"name": "Chris", "scores": [65, 70, 68]}
]

print("--- Class report ---")

for number, student in enumerate(students, start=1):
    average = sum(student["scores"]) / len(student["scores"])
    print(f"{number}. {student['name']}: average {average:.1f}")
    Output 
    --- Class report ---
1. Alex: average 83.7
2. Bo: average 91.7
3. Chris: average 67.7

    Each student is a dictionary holding a list of scores — the exact "list inside a dictionary inside a list" shape this chapter introduced — and sum() / len() turn that inner list into an average.
