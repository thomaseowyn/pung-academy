    Learning material

    Variables: giving a value a name

    So far your programs have had no memory — they print something and immediately forget it. A variable is a name attached to a value, so a program can keep hold of information and use it again later. 

    name = "Alex"
age = 20

    Read the = as "is set to", not as "equals". It is an instruction: take the value on the right, and attach the name on the left to it. From that point on, writing name anywhere in the program means "Alex". 

    name = "Alex"
print("Hello,", name)
    Output 
    Hello, Alex

    Variables exist because information used more than once should be written once. If a value appears in six places and it needs to change, six edits is six chances to miss one — stored in a variable, it changes in a single place and every use follows.

    Tip — naming

    Use lowercase words joined by underscores: first_name, total_price. Names cannot contain spaces or start with a digit, and should say what the thing is — x will cost you time later.

    Data types

    Every value has a type, and the type decides what you can do with it. Adding two numbers gives you their sum; adding two pieces of text glues them together. Python tracks the type of everything so it knows which behaviour you meant.

    The types you need for this chapter:

    • int — a whole number: 20, 0, -7
    • float — a number with a decimal point: 4.50, -0.5
    • str (string) — text, always in quotes: "Alex", "20"
    • bool (boolean) — exactly two possible values: True or False

    You can ask Python what type something is with type():

    print(type(20))
print(type(4.50))
print(type("Alex"))
print(type(True))
    Output 
    <class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
    Careful

    20 and "20" are not the same value. One is a number you can do arithmetic with; the other is two characters of text that happen to look like a number. This single distinction causes more beginner confusion than any other idea in this course.

    Strings

    A string is a sequence of characters. Single and double quotes both work — handy when the text itself contains a quote: 

    greeting = "Hello"
message = "It's a nice day"

    Joining strings together is concatenation, done with +: 

    first = "Ada"
last = "Lovelace"
print(first + " " + last)
    Output 
    Ada Lovelace

    Notice the " " in the middle — without it you would get AdaLovelace. Python only adds exactly what you tell it to.

    f-strings: building text the tidy way

    Gluing strings together with + gets ugly fast, and it fails outright the moment you try to include a number. An f-string lets you drop variables straight into text: put an f before the opening quote and wrap each variable in curly braces. 

    name = "Alex"
age = 20
print(f"{name} is {age} years old")
    Output 
    Alex is 20 years old

    This works for any type — numbers, text, even the result of a calculation — and it is the standard way Python programs build sentences out of data. You will use f-strings constantly from here on.

    Booleans

    A boolean is either True or False — capitalised exactly like that, no quotes. Booleans record whether something is the case, which is what lets a program make decisions in the next chapter. 

    is_logged_in = True
has_paid = False

    Comparisons already produce booleans, even without a full conditional statement: 

    age = 20
print(age >= 18)
    Output 
    True

    Type conversion (casting)

    Type casting turns a value of one type into another. Three functions cover almost everything you need:

    • int(x) — make a whole number
    • float(x) — make a decimal number
    • str(x) — make text

    This matters immediately, because input() — from Chapter 2 — always gives you text, even when someone types a number: 

    age = input("Your age: ")
print(age + 1)
    Output 
    TypeError: can only concatenate str (not "int") to str

    The fix is to convert the text before using it as a number:

    age = int(input("Your age: "))
print(f"Next year you will be {age + 1}")
    Output (with "20" typed) 
    Your age: 20
Next year you will be 21

    Read int(input("Your age: ")) from the inside out: input collects text, and int converts that text into a number. Wrapping one call around another like this is extremely common in Python.

    Careful

    int("hello") fails with a ValueError — there is no sensible number hiding in "hello". Casting only works when the text genuinely looks like the type you are converting to.

    Predict the output

    What type is the result of dividing two whole numbers?

    print(type(10 / 2))
    <class 'float'>

    Division in Python always produces a float, even when the division is exact — 10 / 2 is 5.0, not 5.
