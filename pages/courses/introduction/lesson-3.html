    Learning material

    Why programs need decisions

    Every program you have written so far does exactly the same thing every time it runs. Useful programs react: a login page behaves differently for the right password than the wrong one. A conditional statement lets a program choose between paths, based on a boolean.

    Comparison operators

    A comparison operator compares two values and produces a boolean. 

    a = 17
b = 5

print(a > b)     # greater than              True
print(a < b)     # less than                 False
print(a >= b)    # greater than or equal to  True
print(a <= b)    # less than or equal to     False
print(a == b)    # equal to                  False
print(a != b)    # not equal to              True
    Careful — one equals sign or two?

    = assigns a value. == asks whether two values are the same. age = 18 sets the age to 18. age == 18 asks whether it already is.

    if: the simplest decision

    age = 20

if age >= 18:
    print("You are an adult.")
    Output 
    You are an adult.

    The anatomy of that, piece by piece:

    • if starts the statement.
    • age >= 18 is the condition. It produces True or False.
    • The colon at the end of the line is required.
    • The indented line underneath is the body — it only runs when the condition is True.
    Careful

    Indentation is not decoration in Python — it is how the language knows which lines belong to the if. Use four spaces per level, consistently.

    else: the other path

    age = 15

if age >= 18:
    print("You are an adult.")
else:
    print("You are not an adult yet.")
    Output 
    You are not an adult yet.

    With if/else, exactly one branch runs — never both, never neither.

    elif: more than two options

    elif — short for "else if" — adds extra conditions, tested only if the ones above it were False. 

    score = 74

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "F"

print(f"Your grade is {grade}")
    Output 
    Your grade is C

    Python checks top to bottom and stops at the first match. With a score of 74 it asks "90 or more?" (no), "80 or more?" (no), "70 or more?" (yes) — and skips everything below without testing it.

    Careful — order matters

    Write that same chain starting with score >= 60 and every passing score becomes exactly that grade, because the first true branch catches them all. Always test the narrowest or highest condition first.

    Logical operators: combining conditions

    Often a decision depends on more than one thing at once. Logical operators join conditions together.

    • and — True only when both sides are True
    • or — True when at least one side is True
    • not — flips True to False and back
    age = 20
has_ticket = True

print(age >= 18 and has_ticket)    # True
print(age >= 65 or has_ticket)     # True
print(not has_ticket)              # False

    and is strict — one False ruins it. or is generous — one True is enough. Ranges are the classic use for and: 

    temperature = 22
is_comfortable = temperature >= 18 and temperature <= 25
print(is_comfortable)   # True

    Python also allows the shorter mathematical form for ranges:

    print(18 <= temperature <= 25)   # True

    Nesting conditions

    An if can live inside another if. The inner one is only reached once the outer condition has passed. 

    logged_in = True
is_admin = False

if logged_in:
    print("Welcome back!")
    if is_admin:
        print("You have admin access.")
    else:
        print("You have standard access.")
else:
    print("Please log in.")
    Output 
    Welcome back!
You have standard access.
    Tip

    Deep nesting gets unreadable fast. If you find yourself four levels in, it is usually a sign the conditions should be combined with and instead.

    Small exercise

    What does this print, and why is it probably a bug?

    temperature = 35

if temperature > 0:
    print("Above freezing")
elif temperature > 30:
    print("Very hot")

    It only prints "Above freezing" — the first condition is true, so Python never tests the second. The branches are in the wrong order.
