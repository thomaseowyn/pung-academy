    Learning material

    Why sequences exist

    Storing one number is easy. Storing thirty is not — not with the tools you have so far. You cannot loop over thirty separate variables, and adding a thirty-first means editing the program. A sequence holds many values, in order, under one name.

    Lists

    A list is an ordered, changeable collection. Square brackets, commas between items: 

    grades = [78, 91, 65, 84, 72]
names = ["Alex", "Bo", "Chris"]

    len() tells you how many items a list holds:

    print(len(grades))    # 5

    Tuples

    A tuple looks almost identical to a list but uses round brackets, and — unlike a list — it cannot be changed after it is created. 

    point = (3, 7)
print(point[0])   # 3

    Use a tuple when a value should never change once it exists — coordinates, a fixed pair of settings. Use a list for anything you expect to grow, shrink or reorder.

    Indexing: reaching one item

    Each item has a position, called its index. Indexes start at 0, not 1. 

    names = ["Alex", "Bo", "Chris"]

print(names[0])    # Alex
print(names[1])    # Bo
print(names[2])    # Chris

    Counting from zero feels wrong for about a week and then becomes invisible. The consequence worth memorising: the last item of a list of length 5 sits at index 4.

    Predict the output

    Given names = ["Alex", "Bo", "Chris"], what does negative indexing count from? 

    print(names[-1])
print(names[-2])
    Chris
Bo

    A negative index counts backward from the end — -1 is always the last item, -2 the one before it.

    Careful

    Asking for an index that does not exist crashes with IndexError: list index out of range. With three items, names[3] is already past the end.

    Looping through a sequence

    grades = [78, 91, 65, 84, 72]
total = 0

for grade in grades:
    total += grade

print(f"Average: {total / len(grades)}")
    Output 
    Average: 78.0

    No indexes needed — the loop variable takes each value in turn.

    Finding the largest value by hand

    grades = [78, 91, 65, 84, 72]
highest = grades[0]

for grade in grades:
    if grade > highest:
        highest = grade

print(f"Highest: {highest}")     # 91

    Start by assuming the first item wins, then replace it whenever something better appears. This "running best" pattern appears everywhere once you notice it.
