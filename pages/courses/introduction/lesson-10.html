    Learning material

    Picking up from dictionaries and sets

    Last chapter gave you two new ways to store values: a dictionary for looking things up by name, and a set for uniqueness. This chapter puts them to work inside each other, adds two small looping tools, and covers a subtlety about lists that causes real, confusing bugs if you do not know it is coming.

    Nested data structures

    Structures can hold other structures — a list of dictionaries, or a dictionary whose values are themselves dictionaries. This shape is everywhere once you start working with real data: API responses, JSON files, database records. 

    students = [
    {"name": "Alex", "grade": 78},
    {"name": "Bo", "grade": 91}
]

for student in students:
    print(f"{student['name']}: {student['grade']}")
    Output 
    Alex: 78
Bo: 91

    enumerate() and zip()

    enumerate() gives you the position and the value together while looping: 

    names = ["Alex", "Bo", "Chris"]

for position, name in enumerate(names, start=1):
    print(f"{position}. {name}")
    Output 
    1. Alex
2. Bo
3. Chris

    zip() walks two sequences together, pairing them up item by item:

    Predict the output 
    names = ["Alex", "Bo"]
scores = [78, 91]

for name, score in zip(names, scores):
    print(name, score)
    Alex 78
Bo 91

    Mutability and aliasing

    This is worth taking slowly, because it causes real bugs. Writing a = b for a list does not copy the list — it makes a and b two names for the exact same list. 

    original = [1, 2, 3]
alias = original

alias.append(4)
print(original)   # [1, 2, 3, 4]  -- changed too, even though we edited "alias"

    To get an independent copy, say so explicitly:

    original = [1, 2, 3]
copy = original.copy()

copy.append(4)
print(original)   # [1, 2, 3]  -- untouched
print(copy)        # [1, 2, 3, 4]
    Tip

    This same aliasing happens when you pass a list into a function — the function receives the same list, not a copy. Keep it in mind once you reach functions in the next chapter.

    Worked example — the Student Grade Analyzer

    This chapter's project puts nested structures, aggregation and enumerate() to work together. 

    # Student Grade & Class Performance Analyzer

students = [
    {"name": "Alex", "scores": [78, 82, 91]},
    {"name": "Bo", "scores": [91, 95, 89]},
    {"name": "Chris", "scores": [65, 70, 68]}
]

print("--- Class report ---")

for number, student in enumerate(students, start=1):
    average = sum(student["scores"]) / len(student["scores"])
    print(f"{number}. {student['name']}: average {average:.1f}")
    Output 
    --- Class report ---
1. Alex: average 83.7
2. Bo: average 91.7
3. Chris: average 67.7

    Each student is a dictionary holding a list of scores — the exact "list inside a dictionary inside a list" shape this chapter introduced — and sum() / len() turn that inner list into an average.
