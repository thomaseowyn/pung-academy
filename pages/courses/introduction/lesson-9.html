    Learning material

    Dictionaries: looking things up by name

    A list is indexed by position, which is fine when order is what matters. Often it is not — you want to look something up by name. A dictionary stores key-value pairs. Curly braces, each entry key: value: 

    student = {
    "name": "Alex",
    "age": 20,
    "grade": 78
}

    You look values up by key, not by position:

    print(student["name"])    # Alex
print(student["grade"])   # 78

    Changing and adding

    student["grade"] = 85          # change an existing value
student["city"] = "Jakarta"    # a new key simply appears
del student["age"]             # remove a pair

print(student)
    Output 
    {'name': 'Alex', 'grade': 85, 'city': 'Jakarta'}
    Careful

    Asking for a key that does not exist raises KeyError. Looking up safely is exactly what the next section is for.

    Dictionary methods: .get(), .keys(), .values(), .items()

    student = {"name": "Alex", "grade": 78}

print(student.get("grade"))              # 78
print(student.get("city", "Unknown"))    # Unknown -- the default, since "city" is missing

print(list(student.keys()))     # ['name', 'grade']
print(list(student.values()))   # ['Alex', 78]

for key, value in student.items():
    print(key, "->", value)

    .get(key, default) never raises KeyError — it hands back default instead when the key is missing, which makes it the safe way to read a dictionary you are not certain about. .items() is what lets a loop unpack both the key and the value at once.

    Predict the output

    What does this print, given student = {"name": "Alex", "grade": 78}? 

    print(student.get("email", "none"))
    none

    "email" is not a key in student, so .get() hands back the default you supplied instead of raising an error.

    Sets: uniqueness without order

    A set holds values with no duplicates and no guaranteed order. Curly braces, but no colons: 

    colours = {"red", "green", "blue", "red"}
print(colours)          # {'red', 'green', 'blue'} -- the duplicate is gone

a = {1, 2, 3}
b = {2, 3, 4}
print(a & b)   # {2, 3}         -- intersection: in both
print(a | b)   # {1, 2, 3, 4}   -- union: in either

    Turning a list into a set is the fastest way to remove duplicates: 

    numbers = [1, 2, 2, 3, 3, 3]
unique = set(numbers)
print(unique)    # {1, 2, 3}
