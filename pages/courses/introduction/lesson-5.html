    Learning material

    Picking up from if / elif / else

    Last chapter's conditions each tested one thing: age >= 18, score >= 70. Plenty of real decisions depend on more than one fact at once — "is it the weekend and is the shop open" — which is exactly what this chapter adds.

    Logical operators: combining conditions

    Logical operators join conditions together.

    • and — True only when both sides are True
    • or — True when at least one side is True
    • not — flips True to False and back
    age = 20
has_ticket = True

print(age >= 18 and has_ticket)    # True
print(age >= 65 or has_ticket)     # True
print(not has_ticket)              # False

    and is strict — one False ruins it. or is generous — one True is enough. Ranges are the classic use for and:

    Predict the output 
    temperature = 22
is_comfortable = temperature >= 18 and temperature <= 25
print(is_comfortable)
    True

    22 satisfies both halves of the and — at least 18, and at most 25 — so the whole expression is True.

    Python also allows the shorter mathematical form for ranges:

    print(18 <= temperature <= 25)   # True

    Nesting conditions

    An if can live inside another if. The inner one is only reached once the outer condition has passed. 

    logged_in = True
is_admin = False

if logged_in:
    print("Welcome back!")
    if is_admin:
        print("You have admin access.")
    else:
        print("You have standard access.")
else:
    print("Please log in.")
    Output 
    Welcome back!
You have standard access.
    Tip

    Deep nesting gets unreadable fast. If you find yourself four levels in, it is usually a sign the conditions should be combined with and instead — the nested example above could just as well be written as a single if logged_in and is_admin:.
