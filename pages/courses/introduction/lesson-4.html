    Learning material

    Arithmetic operators

    An operator is a symbol that does something to values. You already met one: +. Here is the full set you need for arithmetic. 

    a = 17
b = 5

print(a + b)    # addition        22
print(a - b)    # subtraction     12
print(a * b)    # multiplication  85
print(a / b)    # division        3.4
print(a // b)   # floor division  3
print(a % b)    # remainder       2
print(a ** b)   # power           1419857

    The last three deserve a proper explanation.

    Division always gives a float

    / gives a decimal answer even when the division is exact. 10 / 2 is 5.0, not 5. If you need a whole number, use //, which divides and throws away anything after the decimal point. 

    print(7 / 2)    # 3.5
print(7 // 2)   # 3

    The remainder operator

    % — usually said "modulo" — gives what is left over after a division. 17 % 5 is 2, because 5 goes into 17 three times with 2 remaining.

    This sounds like a mathematical curiosity and is in fact one of the most useful operators you will ever meet, because x % 2 tells you instantly whether a number is even: 

    print(10 % 2)   # 0  -> even
print(11 % 2)   # 1  -> odd
    Tip

    Anything that repeats in a cycle can be done with %: every third item, wrapping a clock at 12, alternating row colours. Remember it exists.

    Order of operations

    Python follows normal mathematical precedence: powers first, then multiplication and division, then addition and subtraction. Brackets override everything. 

    print(2 + 3 * 4)      # 14  -- the multiplication happens first
print((2 + 3) * 4)    # 20  -- brackets force the addition first

    When in doubt, add brackets. Nobody has ever been confused by too many; plenty of programs have been wrong because of too few.

    Shorthand assignment

    Updating a variable using its own current value is so common it has a shorthand: 

    score = 10

score = score + 5   # the long way
score += 5          # exactly the same thing

print(score)        # 20

    -=, *= and /= work the same way. You will use += constantly once you reach loops.

    Comparison operators

    A comparison operator compares two values and produces a boolean — True or False. These are what decisions are built from. 

    a = 17
b = 5

print(a > b)     # greater than              True
print(a < b)     # less than                 False
print(a >= b)    # greater than or equal to  True
print(a <= b)    # less than or equal to     False
print(a == b)    # equal to                  False
print(a != b)    # not equal to              True
    Careful — one equals sign or two?

    = assigns a value. == asks whether two values are the same. age = 18 sets the age to 18. age == 18 asks whether it already is. Mixing these up is the single most common beginner error in every language that uses both.

    Comparisons work on strings too, and they are case-sensitive:

    print("cat" == "cat")   # True
print("Cat" == "cat")   # False

    Boolean logic

    Often a decision depends on more than one thing at once. "You may enter if you are over 18 and you have a ticket" is two conditions joined together. Logical operators do that joining.

    • and — True only when both sides are True
    • or — True when at least one side is True
    • not — flips True to False and back
    age = 20
has_ticket = True

print(age >= 18 and has_ticket)    # True
print(age >= 65 or has_ticket)     # True
print(not has_ticket)              # False

    Truth tables

    If you are unsure what a combination produces, the complete behaviour of each operator fits in a small table: 

    A       B       A and B    A or B
True    True    True       True
True    False   False      True
False   True    False      True
False   False   False      False

    The pattern worth memorising: and is strict — one False ruins it. or is generous — one True is enough.

    Combining comparisons

    temperature = 22

is_comfortable = temperature >= 18 and temperature <= 25
print(is_comfortable)   # True

    Each comparison produces a boolean first, and then and combines the two booleans. Python also allows the shorter mathematical form for ranges: 

    print(18 <= temperature <= 25)   # True
    Note

    and, or and not are English words in Python. Many other languages use symbols such as && and || for the same thing. The idea is identical.

    Worked example — the Simple Calculator

    This chapter's project. It reads two numbers and reports every operation on them. 

    # Simple Calculator

first = float(input("First number:  "))
second = float(input("Second number: "))

print()
print(f"{first} + {second} = {first + second}")
print(f"{first} - {second} = {first - second}")
print(f"{first} * {second} = {first * second}")
print(f"{first} / {second} = {first / second}")

print()
print(f"Is the first bigger?  {first > second}")
print(f"Are they equal?       {first == second}")
    Output 
    First number:  12
Second number: 4

12.0 + 4.0 = 16.0
12.0 - 4.0 = 8.0
12.0 * 4.0 = 48.0
12.0 / 4.0 = 3.0

Is the first bigger?  True
Are they equal?       False
    Careful

    Run that with a second number of 0 and the division line crashes with ZeroDivisionError. Real programs have to check for that before dividing — which needs an if statement, and that is exactly where the next chapter starts.
