    Picking up from lists and tuples

    Last chapter you could reach one item at a time with an index. This chapter adds a way to reach a whole chunk at once, the methods that let you change a list after it exists, and a real project that leans on both.

    Slicing: reaching a whole chunk

    A slice takes several items at once, written list[start:stop]. The item at start is included; the item at stop is not. 

    letters = ["a", "b", "c", "d", "e"]

print(letters[1:4])    # ['b', 'c', 'd']
print(letters[:2])     # ['a', 'b']       -- start defaults to 0
print(letters[3:])     # ['d', 'e']       -- stop defaults to the end
print(letters[1:-1])   # ['b', 'c', 'd']  -- everything except first and last

    [1:-1] reads naturally once you know -1 means "the last item" — it is "from index 1 up to, but not including, the last one."

    Predict the output

    Given letters = ["a", "b", "c", "d"], what does a slice print when it starts and stops at the same index? 

    print(letters[2:2])
    []

    An empty list — with the same start and stop, there is no room for anything to be included.

    List methods

    Lists can be changed after they are created.

    tasks = ["Wash up", "Email tutor"]

tasks.append("Buy milk")        # add to the end
print(tasks)                    # ['Wash up', 'Email tutor', 'Buy milk']

tasks.pop()                     # remove and return the last item
print(tasks)                    # ['Wash up', 'Email tutor']

tasks.sort()
print(tasks)                    # ['Email tutor', 'Wash up']
    Careful — mutability

    Because lists can change, be careful with a = b where b is a list — a and b then both point at the same list, so changing one changes the other. You will meet this properly, with the fix, in Chapter 10.

    Worked example — the Caesar Cipher

    This chapter's project encrypts a message by shifting every letter forward in the alphabet by a fixed amount, using string indexing, list building and the modulo operator to wrap around from z back to a. 

    # Caesar Cipher

alphabet = "abcdefghijklmnopqrstuvwxyz"
message = input("Message to encrypt: ").lower()
shift = int(input("Shift amount: "))

encrypted = []

for letter in message:
    if letter in alphabet:
        position = alphabet.index(letter)
        new_position = (position + shift) % 26
        encrypted.append(alphabet[new_position])
    else:
        encrypted.append(letter)

print("Encrypted:", "".join(encrypted))
    Output 
    Message to encrypt: hello world
Shift amount: 3
Encrypted: khoor zruog

    alphabet.index(letter) finds a letter's position using a list method you have not met yet — it works the same way on strings. % 26 is what wraps the shift back to the start of the alphabet once it runs past z, and "".join(encrypted) turns the list of letters back into one string.
